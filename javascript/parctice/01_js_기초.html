JS 기초

웹의 3요소

  • HTML(dom트리 구성)
  • CSS : dom요소의 스타일과 디자인 편집
  • JavaScript : 이벤트발생했을때 DOM을 동적으로 조작

자바스트립트란?

웹브라우저에서 주로 사용되는 인터프리터 방식의 스크립트언어
크롬등의 브라우저에서 v8과 같은 자바스크립트엔진이 내장되어 별도의 설치없이 실행가능
*인터 프리터 방식 : 코드를 한줄 읽어가며 즉시 실행하는 방식

자바스크립트 적용 방식

  1. 인라인 방식 : HTML태그의 이벤트 속성 에 직접 자바스크립트 코드를 작성
  2. 내부 방식 : HTML 문서내에 script 태그 내에 자바스크립트 코드를 작성
  3. 외부 방식 : 별도의 .js파일을 생성해서 자바스크립으를 작성

인라인 방식

<태그 on이벤트명 = "자바스크립트코드">

내부 방식

script 태그내에 자바스크립트 작성
HTML요소를 조작할경우 스크립트 대상 요소보다 아래에 위치해야 정상작동함

외부 방식

별도의 자바 스크립트 파일 (.js)를 생성하여 관리하는 방식
