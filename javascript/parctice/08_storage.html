웹스토리지

브라우저 내부에 데이터를 키값을 쌍으로 저장하는 공간
-localstroage : 영구저장 (브라우저나 탭을 닫아도 데이터가 유지됨)
-sessionstroage : 탭단위 저장 (해당 탭을 닫으면 데이터가삭제됨 )
주요 메소드 setItem(key,value) getItem(key) removeItem(key) clear()
참고 웹스토리지 문자열 형태 데이터만 저장할수 있음

localStorage

브라우저를 닫거나 다시 열어도 유지되어야 하는 데이터에 사용
사용자 설정 다크모드 라이트모드 언어 설정
비회원 장바구니 : 로그인 전 장바구니 데이터를 임시보관
오늘 하루 이 창 보지 않기 : 팝업창 만료 시간 및 상태 저장

sessionStroage

데이터가 영구적으로 남으면 안되거나 현재 탭이 유지되는 동안만 일시적으로 저장 작성 폼 백업 : 게시글 작성 중 실수로 새로고침 해도 작성중인 내용 유지 목록상태 유지 : 상품목록 스크롤 위치 및 필터조건을 유지하면서 상세 페이지에서 돌아왔을때 복원
